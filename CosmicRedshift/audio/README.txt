COSMIC REDSHIFT — SLIDE VOICEOVER AUDIO
=======================================

Three files are needed here. The filenames are referenced directly by the
<audio> tag on each slide page and must match exactly:

    slide1.mp3    <- narrate scripts/slide1_script.js
    slide2.mp3    <- narrate scripts/slide2_script.js
    slide3.mp3    <- narrate scripts/slide3_script.js

The text inside each scripts/slideN_script.js file is BOTH the on-screen
transcript (shown when the student presses Start) and the narration source.
If you change the wording in the .js file, re-render the matching .mp3 so
the two stay in sync.

Note: animation/audio/voiceover.mp3 is the animation's OWN narration and is
already in place. It is separate from these three files.
